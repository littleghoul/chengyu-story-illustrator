# 成语图文卡片模板

## 文案模板

```text
成语：{成语}
拼音：{拼音}

核心释义：{用一句话解释准确含义}

成语来源：{用一至两句话概括来源；没有可靠来源时写“未查到稳定来源，本卡以现代用法为准”}

易错提醒：{指出望文生义、感情色彩、对象、程度或近义辨析}

画面记忆钩子：{用一句话说明画面要记住什么}
```

## 版式模板

- 画布：默认竖版 4:5；用户指定比例时服从用户。
- 顶部：成语标题，字号最大；下方放拼音。
- 中部：占主要面积的水墨主图，保持留白。
- 底部：米白色或半透明纸张区域，放释义、来源和易错提醒。
- 图像模型只负责无文字主图；最终交付必须是已经叠加文字的完整卡片。
- 顶部纸张区域放成语和拼音，底部纸张区域依次放核心释义、来源和易错提醒。
- 同时保留无文字主图作为备用素材，但不能用它替代最终图文卡片。

## 确定性排版

生成无文字主图后，运行：

```text
python scripts/compose_card.py \
  --input <无文字主图> \
  --output <最终卡片.png> \
  --idiom "{成语}" \
  --pinyin "{拼音}" \
  --meaning "{核心释义}" \
  --source "{来源简述}" \
  --warning "{易错提醒}"
```

脚本会在上下留白区域绘制标题和学习文案，使用本地中文字体，避免图像模型生成中文字形错误。

## 文案约束

- 核心释义不超过三十个汉字为宜，必要时可略长但保持单句。
- 来源只保留人物、事件、结果和出处中的必要信息。
- 易错提醒必须是可用于做题的判断边界，而不是重复释义。
- 不把未经核实的出处、人物对白或故事细节写成确定事实。

## 参考样例

### 画蛇添足

- 核心释义：做了多余的事，反而把事情弄坏。
- 来源：楚国门客比赛画蛇，有人画完后给蛇添脚，结果失去了酒。
- 易错提醒：重点是“多余”，不是泛指所有错误。
- 画面钩子：已经画好的蛇旁边，正添上的脚成为失败原因。

### 差强人意

- 核心释义：大体上还能让人满意，并非非常满意。
- 来源：原指吴汉能够振奋军心，后来演变为“大体尚可”的意思。
- 易错提醒：“差”不是很差，不能理解为完全不能令人满意。
- 画面钩子：成绩不完美但达到基本标准，人物露出“还可以”的表情。

### 首当其冲

- 核心释义：最先受到攻击或遭遇灾难。
- 来源：若未检索到稳定的百度来源，省略典故，不强行补写。
- 易错提醒：不是“第一个站出来做某事”或“冲锋在前”。
- 画面钩子：洪水或风暴首先冲击最前面的村庄。
